# Unison

Русский | [English](README.md)

Unison переносит буфер обмена, изображения и файлы между вашими устройствами по локальной сети, а
друзьям отправляет отдельные элементы. Доверие устанавливается между устройствами: два устройства
спариваются один раз, и нет ни аккаунта, ни сервиса, которому нужно доверять.

Поддерживаются macOS и Android. Windows и Linux пока недоступны.
