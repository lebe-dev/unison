# Журнал приложения

Русский | [English](application-log.md)

Приложение ведет журнал, который пользователь может отправить в поддержку. По умолчанию он
выключен, и пользователь включает его в Настройках > Журнал приложения. Пока журнал выключен,
приложение не пишет ни одной записи.

## Файлы

Все лежит в `<каталог данных>/logs`:

| Файл | Кто пишет | Назначение |
|------|-----------|------------|
| `journal.log` | ядро (демон на macOS, AAR на Android) | записи кода на Go, ротация на 5 МиБ, три резервные копии |
| `app.log` | оболочка приложения (Rust или Kotlin) | записи оболочки, ротация примерно на 2 МиБ, две резервные копии |
| `journal.on` | тот, кто переключает настройку | маркер: файл существует, пока журнал включен |

Маркер - это общее состояние оболочки и ядра. Ядро читает его при старте, а локальный API
переключает его на лету, поэтому оболочка видит изменение без перезапуска, а позже запущенное
ядро продолжает запись.

На macOS демон также ведет `unisond.log`, JSON-лог, который пишется независимо от журнала. В
общий журнал приложения он не входит.

## Формат

Одна запись на строку:

```
2026-11-17T19:48:02.123Z DEBUG connected to the peer peer=3f2a attempt=2
```

Строка начинается с времени в UTC с миллисекундами, затем идут уровень (`DEBUG`, `INFO`, `WARN`,
`ERROR`), сообщение и атрибуты в виде `key=value`. Значение с пробелами заключается в кавычки.

Ядро пишет каждую запись на уровне debug. Окно фильтрует только показ: `INFO` скрывает записи
debug, `DEBUG` показывает все. Копирование и отправка всегда берут все записи и заголовок
независимо от того, что показывает фильтр.

## Приватность

Записи никогда не содержат содержимое буфера обмена, имена файлов, пути, ключи, токены и данные
спаривания. Абсолютные пути заменяются на `[path]` до записи в файл, так же как в отчетах о
сбоях. Заголовок отправленного журнала содержит версии, имя и ID устройства, состояние сети,
адреса и настройки без секретов; каталог загрузок выглядит как `[path]`.

## Заголовок

Отправленный журнал начинается с версий приложения, демона (macOS) и ядра (Android), версии ОС,
устройства, сети, адресов, настроек и таблицы политики. Строка `---` отделяет заголовок от записей,
которые идут в хронологическом порядке.
